# web_project_around_full

Proyecto 15 — Alrededor de los EE. UU., parte 9: autenticación y conexión con tu propia API.

## Estructura

- `client/` — React (Vite)
- `server/` — Express + MongoDB

## Cómo ejecutar

1. MongoDB en marcha (`aroundb`).
2. Desde la raíz:

```bash
npm run install:all
```

3. En dos terminales:

```bash
npm run dev:server   # http://localhost:3001
npm run dev:client   # http://localhost:3000
```
